# 폭주전설

도로를 위쪽으로 달리며 폭주 차량과 드론을 상대하는 3D 차량 전투 게임입니다. 파일 하나(`index.html`)로 실행되고, 그래픽은 Three.js r128로 그립니다.

현재 버전: **정식 버전 1.6**

## 실행

- `index.html`을 브라우저로 엽니다. Three.js와 글꼴을 인터넷에서 불러오므로 온라인 상태여야 합니다.
- 저장소 설정의 Pages에서 `main` 브랜치를 선택하면 `https://doguri25.github.io/pokju/` 주소로도 열 수 있습니다. (Pages를 켜는 것은 저장소 주인이 직접 해야 합니다.)

## 조작

| 입력 | 키보드 | 터치 | 게임패드 |
| --- | --- | --- | --- |
| 가속·감속 | ↑ ↓ (W S도 됨) | 왼쪽 아래 레버 | 왼쪽 스틱 위아래 |
| 좌우 이동 | ← → (A D도 됨) | 화면 오른쪽을 좌우로 끌기 | 왼쪽 스틱 좌우 |
| 공격 (누르는 동안 발사) | Z, J, 또는 화면의 공격 버튼을 마우스로 누르기 | 레버를 잡고 있는 동안 | RT, RB |
| 기본 기술 | X, E, F | 오른쪽 아래 작은 버튼 | X |
| 고유 기술 | Space, Shift | 오른쪽 아래 큰 버튼 | A, B |
| 시점 바꾸기 | C | 상태 칩의 시점 버튼 | Y |
| 일시정지 | Esc, P | 일시정지 버튼 | Start |
| 소리 끄기 | M | 설정 탭 | |

키보드와 게임패드는 이동과 공격이 따로입니다. 터치 화면에서는 두 엄지가 레버와 방향에 묶여 있어, 레버를 잡고 있는 동안 무기가 나갑니다.

## 들어 있는 것

- 차량 52종 (경차 5종 포함). 실제 판매 차량의 제원(출력, 토크, 중량, 크기)으로 가속과 최고속도, 좌우 이동을 계산합니다. 차 이름은 패러디입니다.
- 미션 38개(6부, 엔딩 4개), 타임어택 7트랙, 레이싱, 서바이벌, 자유 주행
- 배경 8곳(도심, 고속도로, 시골길, 오프로드, 산악, 개울, 눈길, 해안)과 날씨 5가지
- 무기 10종, 보급 아이템 15종, 타이어 6종
- 차량마다 고유 기술 1개와 기본 기술 1개
- 룸미러, 시점 3가지(탑뷰, 낮은 추격 뷰, 운전석)
- 처음 시작할 때 나오는 이야기 4장과 운전 연습 7단계, 미션마다 나오는 무전 대사
- 내구에 따라 달라지는 차량 파손 표현(긁힘, 연기, 불, 기울어짐)

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 바로 열 수 있는 완성 파일 |
| `dist/artifact.html` | Claude 아티팩트에 게시하는 본문 조각 (내용은 같고 문서 머리만 없음) |
| `src/` | 소스 조각 20개. `head3.html`(화면과 스타일) 뒤에 js 조각이 정해진 순서로 이어집니다 |
| `build.sh` | `src/`를 이어 붙여 위 두 파일을 만듭니다 |

## 고친 뒤 다시 만들기

```sh
sh build.sh
```

js 조각은 모두 하나의 함수 안에 들어가므로 `build.sh`에 적힌 순서를 바꾸면 안 됩니다. Node.js가 있으면 문법 확인까지 합니다.

## 알아 둘 점

- 차량 제원 가운데 제조사가 공개하지 않은 최고속도와 0→100 km/h 일부는 추정값입니다. 게임 안 차량 정보에 「추정」으로 표시됩니다.
- 난이도와 균형은 자동 주행 시험으로 맞췄습니다. 사람이 직접 해 본 결과로 조정한 것은 아닙니다.
- iPhone에서 화면을 두 번 터치할 때 뜨는 시스템 돋보기와 복사 말풍선은 터치 처리로 막았습니다(1.4). 실제 iPhone에서 확인한 것은 아니고, 휴대폰 크기의 터치 에뮬레이션으로 확인했습니다.
- 실제 자동차 회사와 관계가 없는 취미 프로젝트입니다.
