# 폭주 구구단

달리는 차로 정답이 적힌 깃발 문을 지나가며 푸는 초등 학습 게임입니다. 첫 과목은 구구단, 다음은 맞춤법입니다. 3D 주행 게임 [폭주전설](https://github.com/doguri25/pokju) 정식 버전 1.6(커밋 `f287e5a`)을 바탕으로 만듭니다.

현재 버전: **준비 중 0.6** (M3: 정답 풍선 맞히기)

기획은 [`docs/PRD.md`](docs/PRD.md)에 있습니다.

## 지금 되는 것

### M3: 정답 풍선 맞히기

- 「구구단」 모드의 「푸는 법」에서 「정답 풍선 맞히기」를 고르면, 깃발 문 대신 숫자가 적힌 풍선이 길 위로 날아와 앞에 멈춰 기다립니다.
- 정답 풍선을 쏘아 맞히면 답입니다. 틀린 풍선을 맞히면 틀린 답이 됩니다.
- 생각할 시간이 지나면 풍선이 다가오고, 끝까지 못 쏘면 차가 들이받는 풍선이 답이 됩니다. 톱이나 미사일만 단 차도 답할 수 있습니다.
- 이야기 모드는 깃발 문 그대로입니다.

### 원작 전투 되살림

- 이야기와 구구단 길에 원작처럼 폭주 차량, 버기, 드론, 자폭 드론, 공중폭격, 추격차, 지나다니는 차가 나옵니다. 무기 10종, 기본·고유 기술, 보급 상자, 아이템 탭, 내구와 파손도 원작 그대로입니다.
- 장이 오를수록 적이 늘어납니다: 1장은 폭주 차량만, 3장부터 드론, 5장부터 공중폭격, 6장부터 자폭 드론, 9장은 모두.
- 학습판에 맞춘 규칙 두 가지
  - 정답을 맞히면 차 내구가 20% 수리됩니다. 문제를 풀수록 오래 버팁니다.
  - 깃발 문이 다가오는 동안에는 공중폭격이 떨어지지 않습니다 (정답 차로가 늘 안전하도록). 폭격은 문제 사이에 옵니다.
- 차가 부서지면 그 판은 끝나고 장은 깨지 못합니다. 그때까지 푼 문제의 기록은 남습니다.
- 「구구단」 모드에서는 「적」 항목으로 적 없이 깃발 문만 나오게 할 수 있습니다. 「연습 주행」은 원작의 자유 주행처럼 적이 없습니다.
- 운전 연습은 원작의 7단계(속도, 차로, 무기, 보급 상자, 기본 기술, 고유 기술, 방지턱)로 되돌렸습니다.
- 자동 시험: 깃발 문 사이에서 게임의 자율주행으로 피하고 정답 문으로 지나가는 시험 차는 7~9장을 내구 36~85를 남기고 깼습니다. 피하지 않고 서 있기만 하면 1장에서도 부서집니다. 사람이 직접 해 본 결과는 아직 없습니다.

### M2.5: 이야기 1부

- 처음 「게임 시작」을 누르면 프롤로그 3장면과 운전 연습 2단계(속도, 차로 바꾸기)가 나오고, 바로 1장으로 이어집니다. 「이야기와 운전 연습」 버튼이나 설정에서 다시 볼 수 있습니다.
- 관제 AI 「마성」이 계산을 까먹어 생긴 숫자 갈림길을 지나며 도시를 고치는 이야기입니다. 마성에 묶인 차와 드론이 덤벼듭니다.
- 9장: 교과서 순서(2·5단 → 3·6단 → 4·8단 → 7단 → 9단 → 1단과 모든 단)대로, 장마다 다른 배경 8곳과 고칠 것(신호등, 버스 시간표, 다리 차단기, 케이블카, 톨게이트, 택배 창고, 제설차, 등대, 마성의 계산 칩)이 있습니다.
- 장의 첫 판은 순서대로, 다시 하면 섞어서 나옵니다. 7할 이상 맞히면 다음 장이 열리고 별 1~3개를 받습니다.
- 판 중간에 새벽이 무전으로 그 단의 요령을 알려 줍니다 (예: 「9단은 십의 자리와 일의 자리를 더하면 늘 9야」).
- 9장을 깨면 엔딩이 나오고, 맞춤법 2부를 예고합니다.
- 고친 것: 원본에서 「운전 연습을 마쳤다」는 기록을 저장만 하고 읽지 않아, 새로 열 때마다 프롤로그가 다시 나오던 문제.

### M2: 반복 학습과 기록

- 문제마다 처음 답한 결과를 모아 숙달 정도를 넷으로 나눕니다: 잘함(세 번 연속 맞힘), 연습 중, 어려움(틀린 뒤 아직 못 맞힘), 처음.
- 「섞어서」·「빈칸 찾기」·「거꾸로」 문제는 약한 문제 약 40%, 처음 보는 문제 약 40%, 잘하는 문제 약 20%로 고릅니다.
- 「기록」 탭에 2단~9단 9×9 표와 최근 기록 10판이 나옵니다. 표는 색과 기호(★ ● ▲)를 함께 써서 색을 구분하기 어려워도 읽힙니다.
- 결과 화면에도 그 판의 단을 9×9 표로 보여 주고, 방금 나온 문제에 테두리를 칩니다.

### M1: 구구단 깃발 문

- 「모드」 탭의 「구구단」에서 단(2~9단, 2·5단 같은 묶음, 모두), 문제 유형, 생각할 시간을 고르고 출발합니다.
- 문제가 화면 위에 뜨고, 정답이 적힌 깃발 문이 길을 나눠 다가옵니다. 지나간 문이 답입니다.
- 문제 유형: 순서대로·섞어서(보기 2개), 빈칸 찾기(보기 3개), 거꾸로(보기 4개).
- 맞으면 짧게 가속하고 연속 정답을 셉니다. 틀리면 잠깐 느려지고 정답을 보여 주며, 그 문제는 끝에 한 번 더 나옵니다.
- 헷갈리는 보기는 아이들이 실제로 잘 틀리는 답(이웃 곱, 끝자리 같은 수, 덧셈)으로 만듭니다.
- 결과 화면에 맞힌 수, 가장 긴 연속 정답, 다시 볼 문제가 나옵니다.
- 맞힌 문제마다 고철 20을 받아 차량을 열 수 있습니다.

### M0: 학습판 껍데기

- 제목과 문구를 학습판으로 바꿨습니다.
- 「연습 주행」은 문제 없이 일반 차량만 다니는 길을 달립니다.
- 원작 전투는 `src/part_base.js`의 `EDU.arms` 하나로 켜고 끕니다 (지금은 켜져 있음).
- 원본의 미션, 타임어택, 레이싱, 서바이벌, 예고편은 화면에서 감췄습니다.
- 배경음악은 기본으로 꺼져 있습니다 (교실에 기기가 많기 때문).
- 기록은 이 브라우저에만 `pokju-edu-v1` 이름으로 저장되고, 원본 게임 기록과 섞이지 않습니다.

## 실행

- `index.html`을 브라우저로 엽니다. Three.js와 글꼴을 인터넷에서 불러오므로 온라인 상태여야 합니다.
- 저장소 설정의 Pages에서 `main` 브랜치를 선택하면 `https://doguri25.github.io/pokju-edu/` 주소로도 열 수 있습니다. (Pages를 켜는 것은 저장소 주인이 직접 해야 합니다.)

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 바로 열 수 있는 완성 파일 |
| `dist/artifact.html` | Claude 아티팩트에 게시하는 본문 조각 (내용은 같고 문서 머리만 없음) |
| `src/` | 소스 조각. `head3.html`(화면과 스타일) 뒤에 js 조각이 정해진 순서로 이어집니다. 학습판에서 새로 만든 것은 `js_quiz.js`(출제기), `js_gate.js`(깃발 문, 문제 화면, 결과, 기록), `js_chapters.js`(이야기 9장) |
| `build.sh` | `src/`를 이어 붙여 위 두 파일을 만듭니다 |
| `docs/PRD.md` | 학습판 기획 문서 |
| `tests/` | 출제기 시험 |

## 고친 뒤 다시 만들기

```sh
sh build.sh
```

js 조각은 모두 하나의 함수 안에 들어가므로 `build.sh`에 적힌 순서를 바꾸면 안 됩니다. Node.js가 있으면 문법 확인까지 합니다.

구구단 출제기(`src/js_quiz.js`)는 3D와 떨어진 순수 함수라 따로 시험합니다.

```sh
node tests/quiz.test.js
```

## 알아 둘 점

- 차량 제원 가운데 제조사가 공개하지 않은 최고속도와 0→100 km/h 일부는 추정값입니다. 게임 안 차량 정보에 「추정」으로 표시됩니다.
- 실제 자동차 회사와 관계가 없는 취미 프로젝트입니다. 차 이름은 패러디입니다.
