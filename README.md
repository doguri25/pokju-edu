# 폭주 구구단

달리는 차로 정답이 적힌 깃발 문을 지나가며 푸는 초등 학습 게임입니다. 첫 과목은 구구단, 다음은 맞춤법입니다. 3D 주행 게임 [폭주전설](https://github.com/doguri25/pokju) 정식 버전 1.6(커밋 `f287e5a`)을 바탕으로 만듭니다.

현재 버전: **정식 버전 1.1** (바뀐 내용은 [`CHANGELOG.md`](CHANGELOG.md))

기획은 [`docs/PRD.md`](docs/PRD.md)에 있습니다.

## 지금 되는 것

### 정식 버전 1.1

- **백미러가 사라지던 문제:** 화질 「자동」이 프레임이 느릴 때 「낮음」으로 내려가면서 백미러를 꺼 버렸습니다. 이제 백미러는 모든 화질에서 보이고(낮음은 2프레임마다, 조금 작게), 자동 화질은 효과를 끄기 전에 해상도부터 조금씩(100% → 85% → 72%) 낮춥니다. 30Hz로 도는 기기(휴대폰 절전 모드)를 느린 기기로 잘못 보지 않도록 화면의 실제 주사율에 맞춰 판단하고, 한 번 멈칫한 프레임은 세지 않으며(중앙값), 메뉴·일시정지 중에는 재지 않습니다. 빨라지면 해상도를 다시 올립니다.
- **원경:** 지평선 너머에 지역마다 다른 실루엣 고리를 그립니다(`src/shaders/skyline.frag`). 도심·고속도로는 빌딩 숲(밤에는 창문 불빛과 고층 빌딩 꼭대기의 깜빡이는 빨간 등), 시골·개울은 언덕(밤에는 마을 불빛), 산악·오프로드는 능선, 눈길은 눈 덮인 봉우리, 해안은 바다 쪽이 트인 언덕. 멀수록 하늘색에 묻히고 비와 안개 속에서는 흐려집니다.
- **비 오는 렌즈:** 비가 오면 화면에 빗방울이 맺혀 뒤 풍경을 굴절시키고, 흘러내리다 마릅니다. 터널 안에서는 생기지 않고 「화면 흔들림과 번쩍임 줄이기」를 켜면 꺼집니다.
- **백미러 하늘:** 하늘을 먼 평면에 그리도록 바꿔 백미러에도 구름과 하늘이 비칩니다.
- **반사:** 하늘 환경 맵을 빛의 세기(선형)로 구워 차체·유리·젖은 도로 반사가 덜 뿌옇습니다. 「투싼타」 도장도 이제 클리어코트로 바뀝니다. 차량 카드 사진도 게임과 같은 톤 매핑을 씁니다.
- **언덕 위 빛:** 전조등 빛 웅덩이, 가로등 반사, 깃발 문 화살표가 언덕 꼭대기에서 도로 속으로 꺼지지 않습니다.
- **먼 도로 선명하게:** 도로·갓길·들판 텍스처에 이방성 필터를 높였습니다.
- **최적화:** 하늘을 맨 마지막에 그려 가려진 곳의 구름 계산을 건너뜁니다. 후처리 버퍼를 한 벌만 쓰고(고해상도 화면에서 수백 MB 절약), 빛 번짐 크기에 상한을 두고, 「보통」·「낮음」은 멀티샘플을 2로 줄였습니다. 후처리를 쓸 수 있는 기기에서는 캔버스 자체의 멀티샘플을 끕니다. 「낮음」도 화면 마무리(정답 섬광, 빗방울, 안티에일리어싱)는 그대로 하고 빛 번짐만 끕니다.
- **호환:** 반쪽 정밀도 버퍼를 못 쓰는 기기는 예전처럼 바로 그립니다. 오래된 iPad(iPadOS 15)에서 시작하자마자 멈추던 문제(Canvas `roundRect`)를 고쳤습니다. 그래픽 문맥이 복구되면 반사 맵을 다시 굽습니다.

### 정식 버전 1.0

- **젖은 도로:** 비 오는 날에는 도로가 하늘을 비추고(하늘 셰이더로 만든 환경 맵), 밤에는 마른 도로도 조금 반짝입니다. 가로등 아래에 길게 늘어진 빛 반사, 내 차 꼬리등의 붉은 반사가 생깁니다.
- **노을·밤 장:** 이야기 18장 가운데 낮 4장, 노을 8장, 밤 6장(비 오는 밤 2장, 눈 오는 밤 1장 포함)으로 바꿨습니다.
- **자동차:** 52종 모두 클리어코트 도장과 둥글게 다듬은 모서리, 하늘이 비치는 유리와 크롬, 둥근 어깨를 가진 타이어와 크롬 림 테두리로 바꿨습니다.
- **백미러:** 2~3프레임마다 한 번씩 그리던 것을 매 프레임 그리도록 바꿔 끊기지 않습니다(크기를 줄여 부담을 낮춤). 본 화면과 같은 톤 매핑을 써서 색도 맞습니다.
- **문제 카드:** 백미러 바로 아래에 오도록 바꿔 휴대폰에서도 겹치지 않습니다.

### 그래픽 업그레이드 1단계 (목업 따라가기)

- **빌드:** Vite로 옮겼습니다. Three.js r187을 npm에서 함께 묶어 `index.html` 한 파일에 넣으므로 Three.js를 CDN에서 따로 받지 않습니다 (글꼴만 인터넷에서 받음).
- **Three.js r128 → r187:** 예전 모습을 그대로 유지하도록 색 관리, 빛 세기(π 배), 빛의 거리 감쇠(r128 공식)를 맞췄고, 낮·노을·밤 화면을 예전 빌드와 나란히 찍어 비교했습니다.
- **후처리:** 장면 → 빛 번짐(Bloom) → GLSL 색 보정(`src/shaders/grade.frag`). 니트로 때 화면 가장자리 흐림과 색수차, 밤의 푸른 그늘과 노을의 따뜻한 빛, 정답 초록·오답 빨강 섬광, 필름 그레인.
- **하늘:** 새 GLSL 하늘(`src/shaders/sky.frag`): 겹겹이 움직이며 해 쪽이 밝은 구름, 노을의 분홍 띠와 지평선 빛, 달, 반짝이는 별.
- **빛나는 것:** 노을과 밤에는 가로등, 전조등, 꼬리등, 창문, 네온이 흰색보다 밝아져 빛이 번집니다.
- **네온 도시:** 도심 건물에 Canvas2D로 그린 한글 네온 간판(전설 카센터, 구구단 학원, 맞춤법 서점…)과 세로 네온 띠. 낮에는 간판으로, 노을과 밤에는 빛나는 네온으로 보입니다.
- **깃발 문:** 답마다 그 색의 네온 틀, 광택 있는 정답판, 문 앞 차로에 흐르는 빛 화살표. 답을 고르면 네온이 번쩍입니다.
- **화면 디자인(목업):** 어두운 유리 패널과 하늘색→보라→분홍 그라데이션. 주행 화면에 문제 카드와 남은 시간 막대, 10문제 진행 점, 칸으로 나뉜 내구 막대, 연속 정답 배지, Canvas2D 원형 속도계, 쿨타임이 원으로 차는 둥근 기술 버튼, 가운데의 큰 「정답!」 알림.
- **차량:** 52종 모두 처음부터 쓸 수 있고, 각 차의 기본 무기도 함께 열립니다.
- **화질 단계:** 「낮음」에서는 빛 번짐을 끄고 그림자를 끕니다(1.1부터 백미러는 모든 단계에서 보임).

### M5: 수업 링크

- 「모드」 탭 아래 「수업 링크 만들기」를 누르면 지금 고른 모드와 설정(단, 문제 유형, 맞춤법 묶음, 적, 푸는 법, 생각할 시간, 이야기 장)이 담긴 주소가 만들어지고 복사됩니다.
- 학생이 그 주소로 열면 프롤로그를 건너뛰고 「게임 시작」 → 「출발」 두 번으로 그 설정 그대로 시작합니다. 이야기 링크는 아직 잠긴 장도 엽니다.
- 주소에 설정만 담기고 어디로도 보내지 않습니다. 기록은 학생 기기에만 남습니다.
- 예: `?m=quiz&dan=7&type=mix&foe=off&style=gate&pace=mid`, `?m=spell&set=dwae`, `?m=story&ch=10`
- GitHub Pages 주소에서 쓰는 것을 전제로 합니다.
- 결과 화면의 「크게 보기」를 누르면 결과가 화면 가득 큰 글씨로 나옵니다. 칠판이나 TV에 띄울 때 씁니다.

### M4: 맞춤법과 이야기 2부

- 새 모드 「맞춤법」: 빈칸이 있는 문장이 나오고, 바른 말이 적힌 문(또는 풍선)을 고릅니다. 틀리면 정답 문장과 까닭을 보여 줍니다.
- 묶음 10개, 문장 67개: 되/돼, 안/않, 맞히다/맞추다, 웬/왠, 든지/던지, 가르치다/가리키다, 낫다/낮다/났다/낳다(보기 3개), 자주 틀리는 말(며칠, 금세, 일부러, 어떡해…), 바라다/바래다, 로서/로써.
- 문장은 `data/spell.json`에 있어 선생님이 고치거나 더할 수 있습니다. 고친 뒤 `sh build.sh`, `node tests/quiz.test.js`로 형식을 확인합니다.
- 구구단과 같은 반복 학습(약한 문장을 더 자주)과 기록을 씁니다. 「기록」 탭에 묶음별 숙달 표가 생겼습니다.
- 이야기 2부 「글자 칩」 9장(10~18장): 1부를 깨면 열립니다. 전광판, 마을 방송, 안내판, 등대 일지의 틀린 글자를 고치고, 18장 마성 타워에서 모든 묶음을 풉니다. 2부 엔딩이 있습니다.
- 깃발 문 글자가 길면 크기를 줄여 맞추고, 차가 문 아래를 지날 때는 글자판이 흐려져 화면을 가리지 않습니다.

### M3: 정답 풍선 맞히기

- 「구구단」 모드의 「푸는 법」에서 「정답 풍선 맞히기」를 고르면, 깃발 문 대신 숫자가 적힌 풍선이 길 위로 날아와 앞에 멈춰 기다립니다.
- 정답 풍선을 쏘아 맞히면 답입니다. 틀린 풍선을 맞히면 틀린 답이 됩니다.
- 생각할 시간이 지나면 풍선이 다가오고, 끝까지 못 쏘면 차가 들이받는 풍선이 답이 됩니다. 톱이나 미사일만 단 차도 답할 수 있습니다.
- 이야기 모드는 깃발 문 그대로입니다.

### 원작 전투 되살림

- 이야기와 구구단 길에 원작처럼 폭주 차량, 버기, 드론, 자폭 드론, 공중폭격, 추격차, 지나다니는 차가 나옵니다. 무기 10종, 기본·고유 기술, 보급 상자, 아이템 탭, 내구와 파손도 원작 그대로입니다.
- 장이 오를수록 적이 늘어납니다: 1장은 폭주 차량만, 3장부터 드론, 5장부터 공중폭격, 6장부터 자폭 드론, 9장은 모두.
- 학습판에 맞춘 규칙 두 가지
  - 정답을 맞히면 차 내구가 20% 수리됩니다. 문제를 풀수록 오래 버팁니다.
  - 깃발 문이 다가오는 동안에는 공중폭격이 떨어지지 않습니다 (정답 차로가 늘 안전하도록). 폭격은 문제 사이에 옵니다.
- 차가 부서지면 그 판은 끝나고 장은 깨지 못합니다. 그때까지 푼 문제의 기록은 남습니다.
- 「구구단」 모드에서는 「적」 항목으로 적 없이 깃발 문만 나오게 할 수 있습니다. 「연습 주행」은 원작의 자유 주행처럼 적이 없습니다.
- 운전 연습은 원작의 7단계(속도, 차로, 무기, 보급 상자, 기본 기술, 고유 기술, 방지턱)로 되돌렸습니다.
- 자동 시험: 깃발 문 사이에서 게임의 자율주행으로 피하고 정답 문으로 지나가는 시험 차는 7~9장을 내구 36~85를 남기고 깼습니다. 피하지 않고 서 있기만 하면 1장에서도 부서집니다. 사람이 직접 해 본 결과는 아직 없습니다.

### M2.5: 이야기 1부

- 처음 「게임 시작」을 누르면 프롤로그 3장면과 운전 연습 2단계(속도, 차로 바꾸기)가 나오고, 바로 1장으로 이어집니다. 「이야기와 운전 연습」 버튼이나 설정에서 다시 볼 수 있습니다.
- 관제 AI 「마성」이 계산을 까먹어 생긴 숫자 갈림길을 지나며 도시를 고치는 이야기입니다. 마성에 묶인 차와 드론이 덤벼듭니다.
- 9장: 교과서 순서(2·5단 → 3·6단 → 4·8단 → 7단 → 9단 → 1단과 모든 단)대로, 장마다 다른 배경 8곳과 고칠 것(신호등, 버스 시간표, 다리 차단기, 케이블카, 톨게이트, 택배 창고, 제설차, 등대, 마성의 계산 칩)이 있습니다.
- 장의 첫 판은 순서대로, 다시 하면 섞어서 나옵니다. 7할 이상 맞히면 다음 장이 열리고 별 1~3개를 받습니다.
- 판 중간에 새벽이 무전으로 그 단의 요령을 알려 줍니다 (예: 「9단은 십의 자리와 일의 자리를 더하면 늘 9야」).
- 9장 마성 타워에는 1단과 모든 단, 0의 곱(7×0)이 섞여 나옵니다. 깨면 엔딩이 나오고 맞춤법 2부가 열립니다.
- 고친 것: 원본에서 「운전 연습을 마쳤다」는 기록을 저장만 하고 읽지 않아, 새로 열 때마다 프롤로그가 다시 나오던 문제.

### M2: 반복 학습과 기록

- 문제마다 처음 답한 결과를 모아 숙달 정도를 넷으로 나눕니다: 잘함(세 번 연속 맞힘), 연습 중, 어려움(틀린 뒤 아직 못 맞힘), 처음.
- 「섞어서」·「빈칸 찾기」·「거꾸로」 문제는 약한 문제 약 40%, 처음 보는 문제 약 40%, 잘하는 문제 약 20%로 고릅니다.
- 「기록」 탭에 2단~9단 9×9 표와 최근 기록 10판이 나옵니다. 표는 색과 기호(★ ● ▲)를 함께 써서 색을 구분하기 어려워도 읽힙니다.
- 결과 화면에도 그 판의 단을 9×9 표로 보여 주고, 방금 나온 문제에 테두리를 칩니다.

### M1: 구구단 깃발 문

- 「모드」 탭의 「구구단」에서 단(2~9단, 2·5단 같은 묶음, 모두), 문제 유형, 생각할 시간을 고르고 출발합니다.
- 문제가 화면 위에 뜨고, 정답이 적힌 깃발 문이 길을 나눠 다가옵니다. 지나간 문이 답입니다.
- 문제 유형: 순서대로·섞어서(보기 2개), 빈칸 찾기(보기 3개), 거꾸로(보기 4개).
- 맞으면 짧게 가속하고 연속 정답을 셉니다. 틀리면 잠깐 느려지고 정답을 보여 주며, 그 문제는 끝에 한 번 더 나옵니다.
- 헷갈리는 보기는 아이들이 실제로 잘 틀리는 답(이웃 곱, 끝자리 같은 수, 덧셈)으로 만듭니다.
- 결과 화면에 맞힌 수, 가장 긴 연속 정답, 다시 볼 문제가 나옵니다.
- 맞힌 문제마다 고철 20을 받아 차량을 열 수 있습니다.

## 고친 뒤 다시 만들기

```sh
npm install        # 처음 한 번
npm run build      # index.html 과 dist/artifact.html 만들기 (sh build.sh 도 같음)
npm run dev        # 개발 서버: src/ 를 고치면 바로 다시 만듦
npm test           # 출제기와 맞춤법 묶음 시험
```

js 조각은 모두 하나의 함수 안에 들어가므로 `tools/build.mjs`의 `PARTS` 순서를 바꾸면 안 됩니다. 문법 오류가 있으면 Vite 빌드가 멈추고 알려 줍니다.

출제기(`src/js_quiz.js`)는 3D와 떨어진 순수 함수라 따로 시험합니다. 맞춤법 묶음 파일의 형식(빈칸 하나, 보기 2~4개, 설명)도 함께 확인합니다.

```sh
node tests/quiz.test.js
```

## 알아 둘 점

- 차량 제원 가운데 제조사가 공개하지 않은 최고속도와 0→100 km/h 일부는 추정값입니다. 게임 안 차량 정보에 「추정」으로 표시됩니다.
- 실제 자동차 회사와 관계가 없는 취미 프로젝트입니다. 차 이름은 패러디입니다.
