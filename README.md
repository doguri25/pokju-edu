# 폭주 구구단

달리는 차로 정답이 적힌 깃발 문을 지나가며 푸는 초등 학습 게임입니다. 첫 과목은 구구단, 다음은 맞춤법입니다. 3D 주행 게임 [폭주전설](https://github.com/doguri25/pokju) 정식 버전 1.6(커밋 `f287e5a`)을 바탕으로 만듭니다.

현재 버전: **준비 중 0.1** (M0: 학습판 껍데기)

기획은 [`docs/PRD.md`](docs/PRD.md)에 있습니다.

## 지금 되는 것 (M0)

- 제목과 문구를 학습판으로 바꿨습니다.
- 모드는 「연습 주행」 하나입니다. 적 없이 일반 차량만 다니는 길을 달립니다.
- 무기, 기술, 보급 상자는 꺼 두었습니다. 코드는 남아 있고 `src/part_base.js`의 `EDU.arms` 하나로 켜고 끕니다. 맞히기 모드(M3)에서 순한 무기 1종만 다시 켭니다.
- 원본의 미션, 타임어택, 레이싱, 서바이벌, 이야기, 예고편은 화면에서 감췄습니다. 학습판 이야기(M2.5)로 바꿀 예정입니다.
- 배경음악은 기본으로 꺼져 있습니다 (교실에 기기가 많기 때문).
- 기록은 이 브라우저에만 `pokju-edu-v1` 이름으로 저장되고, 원본 게임 기록과 섞이지 않습니다.

## 실행

- `index.html`을 브라우저로 엽니다. Three.js와 글꼴을 인터넷에서 불러오므로 온라인 상태여야 합니다.
- 저장소 설정의 Pages에서 `main` 브랜치를 선택하면 `https://doguri25.github.io/pokju-edu/` 주소로도 열 수 있습니다. (Pages를 켜는 것은 저장소 주인이 직접 해야 합니다.)

## 조작

| 입력 | 키보드 | 터치 | 게임패드 |
| --- | --- | --- | --- |
| 가속·감속 | ↑ ↓ (W S도 됨) | 왼쪽 아래 레버 | 왼쪽 스틱 위아래 |
| 좌우 이동 | ← → (A D도 됨) | 화면 오른쪽을 좌우로 끌기 | 왼쪽 스틱 좌우 |
| 시점 바꾸기 | C | 상태 칩의 시점 버튼 | Y |
| 일시정지 | Esc, P | 일시정지 버튼 | Start |
| 소리 끄기 | M | 설정 탭 | |

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 바로 열 수 있는 완성 파일 |
| `dist/artifact.html` | Claude 아티팩트에 게시하는 본문 조각 (내용은 같고 문서 머리만 없음) |
| `src/` | 소스 조각. `head3.html`(화면과 스타일) 뒤에 js 조각이 정해진 순서로 이어집니다 |
| `build.sh` | `src/`를 이어 붙여 위 두 파일을 만듭니다 |
| `docs/PRD.md` | 학습판 기획 문서 |

## 고친 뒤 다시 만들기

```sh
sh build.sh
```

js 조각은 모두 하나의 함수 안에 들어가므로 `build.sh`에 적힌 순서를 바꾸면 안 됩니다. Node.js가 있으면 문법 확인까지 합니다.

## 알아 둘 점

- 차량 제원 가운데 제조사가 공개하지 않은 최고속도와 0→100 km/h 일부는 추정값입니다. 게임 안 차량 정보에 「추정」으로 표시됩니다.
- 실제 자동차 회사와 관계가 없는 취미 프로젝트입니다. 차 이름은 패러디입니다.
