# 그래픽 업그레이드 목업

폭주 구구단의 주행 화면 하나를 새 기술 묶음으로 다시 그린 목업입니다. 게임 본체(`../index.html`)와는 따로 떨어져 있고, 본체는 바뀌지 않았습니다.
화면은 스스로 돌아갑니다: 차가 문제를 읽고 정답 문으로 차로를 바꾸고, 드론을 쏘고, 네 번째 문제마다 일부러 틀려 두 가지 피드백을 모두 보여 줍니다.

## 쓰인 기술과 맡은 일

| 기술 | 이 화면에서 하는 일 |
| --- | --- |
| Three.js r187 + WebGL2 | 장면, 둥근 차체에 클리어코트 PBR 도장, 하늘 셰이더를 구워 만든 환경 맵으로 노을이 차에 비침 |
| GLSL (`src/shaders/`) | 노을 하늘(구름, 해, 별), 비 온 뒤 젖은 도로(물웅덩이, 하늘·가로등 반사, 전조등 빛, 그림자), 깃발 문의 네온 관, 차로 위 빛 화살표, 마지막 색 보정(속도에 따른 색수차·가장자리 흐림, 비네트, 정답·오답 섬광, 필름 그레인) |
| Canvas2D (`src/textures.js`, `src/hud.js`) | 모든 텍스처(창문 켜진 건물 벽, 한글 네온 간판, 정답판, 빛 번짐)와 HUD 전체(문제 카드, 진행 점, 내구, 연속 정답, 속도계, 기술 버튼, 정답 알림) |
| Vite | 개발 서버, GLSL 파일을 `?raw`로 불러오기, 한 번에 빌드 |
| 후처리 | Bloom → GLSL 색 보정 → ACES 톤 매핑 |

이미지 파일은 하나도 쓰지 않습니다. 글꼴만 Google Fonts에서 받습니다.

## 실행

```sh
cd mockup
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 에 빌드
npm run preview    # 빌드 결과 보기
```

빌드 결과는 `dist/`에 함께 올려 두었습니다. 저장소의 GitHub Pages를 켜면 `https://doguri25.github.io/pokju-edu/mockup/dist/` 에서 바로 볼 수 있습니다.

## 확인한 것

- 헤드리스 Chromium(SwiftShader WebGL2)에서 PC 1280×720, 휴대폰 세로 390×844로 화면을 찍어 확인했습니다. 셰이더 컴파일 오류는 없습니다.
- 실제 GPU, 실제 휴대폰에서의 프레임 수는 아직 재지 않았습니다. 보급형 기기에서는 Bloom 해상도와 건물 수를 줄이는 화질 단계가 필요할 수 있습니다.
